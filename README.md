## ✨ About

**Ollywood Food Cafe** is a modern, responsive web experience created for a food cafe to bring its menu and brand online.

The project focuses on a clean visual interface, easy menu discovery, and a smooth experience across desktop and mobile devices.

> **Good food deserves a good digital experience.**

## 🎯 Project Goals

The project was created with a few simple goals:

* Give the cafe a professional online presence
* Make the menu easier to discover
* Create a visually engaging food experience
* Ensure the website works across different screen sizes
* Build a foundation for future online ordering features

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate to the project:

```bash
cd ollywood-food-cafe
```

Open `index.html` in your browser.

For local development, you can also use **VS Code Live Server** or any static web server.
